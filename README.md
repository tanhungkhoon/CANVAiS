# CANVAiS

CANVAiS or **C**ontext-**A**ware **N**aturally **V**ibe **Ai** **S**ketcher is a drawing tool for plotting objects in different layers on a base map using geographical tool, implemented as a Java Springboot application. It is driven by blending various AI technologies such as naturally spoken vibe and freehand visual intent that create graphical objects on a map layered with different types of entities, with semantics, to provide the context on how to draw the objects.

CANVAiS also supports creation of customized layer with customized graphical objects, with semantics, for each layer using AI skill plugins or integrations with MCP servers.
